Speed up `fit_mode="fit_with_cache"` prediction by running the whole ensemble in one batched forward instead of one forward per estimator: 1.4x faster on an RTX PRO 6000 at 200k train rows and 8 estimators, up to 2.8x when each estimator's forward is smaller. Large test batches keep the previous per-estimator path, and the many-class decoder now caches its keys in the layout attention wants, which lowers cached-predict memory whether or not the ensemble is batched. Predicted probabilities can shift by around 1e-4 because batching changes the order attention sums in; predicted labels and regression means are unaffected.
