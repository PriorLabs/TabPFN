`FeatureModality.TEXT` has been removed. A string column with more than `MIN_CARDINALITY_FOR_TEXT` distinct values is labelled `NUMERICAL`, which is how the model always treated it: ordinal-encoded by the alphabetical rank of each string and fed as a number. The free-text warning about such a column is still raised, now by the text transformer before validation rather than by modality detection after it, so it also names `object` columns. With GPU preprocessing on, such a column now goes through the numeric GPU steps like every other numeric column, instead of being skipped.
