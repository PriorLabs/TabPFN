Inside `overwrite_fit_input()`, `fit` frees the memory of its input while it cleans it. It empties a frame after the targets are validated and frees the frame's blocks during cleaning. For a float32 table, it casts a wider numeric array to float32 in the array's own memory. A fit never writes into the memory of a read-only array or of an array that another fitted model reads. A fit refuses an input whose memory an earlier fit overwrote.
