A column declared categorical is now taken at face value. A pandas `category` column counts as declared, so its position is merged into `categorical_features_indices` at fit (the merged list is exposed as `categorical_features_indices_`), and a declared string column is read as categorical whatever its cardinality, never as text. Before, a declared string column with more than `MIN_CARDINALITY_FOR_TEXT` distinct values was still ordinal-encoded as text and not presented to the model as categorical (declaring it only silenced the free-text warning), and a `category` dtype was not a declaration at all. `MIN_CARDINALITY_FOR_TEXT` now only sorts undeclared string columns into category or text.
