Passing an `InferenceConfig` object as `inference_config` is deprecated and now emits a `FutureWarning`. Unlike a dict, which overrides only the keys it names, an object replaces the checkpoint's config as a whole, so every field it does not set takes a class default rather than the checkpoint-specific value — which can silently degrade predictions. Pass a dict of just the settings you want to change; `dataclasses.asdict(config)` reproduces the old behavior for callers that do want a full replacement.
