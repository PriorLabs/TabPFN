`n_estimators` now defaults to `"auto"` on `TabPFNClassifier` and `TabPFNRegressor`. Feature-coverage auto-scaling (raising `n_estimators` on wide datasets so every feature is seen by some estimator) applies only to `"auto"` — an explicitly passed `n_estimators` is always used exactly as given, and warns at fit time if it is too small for every feature to be covered.
