`InferenceConfig.SVD_EXTRA_RANDOM_COMPONENT_FRACTION` (default `0.0`, so predictions are unchanged unless you opt in) makes the SVD feature step decompose the full spectrum and append extra components drawn at random from below the top-k, redrawn per ensemble member. Until now the step added only the top-k components, which are identical for every member, so the SVD features carried no ensemble diversity at all. Setting `0.5` adds half as many components again per member, each seeing different low-variance directions of the same data. Both the CPU and the GPU preprocessing paths implement it, and select the same components for the same seed. Decomposing the full spectrum costs roughly 1.2-1.7x the SVD step's time, and the extras reach into the tail of the spectrum, where the components of a rank-deficient table are close to arbitrary.
