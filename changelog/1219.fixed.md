Fix the opt-in built-model cache (`TABPFN_MODEL_CACHE_SIZE`) serving a model placed for a different device or inference precision. An estimator applies both to the model it is given, in place, so fitting at one setting and then another in the same process raised errors such as `mat1 and mat2 must have the same dtype, but got Float and Half` or `Placeholder storage has not been allocated on MPS device!`. Both are now part of the cache key.
