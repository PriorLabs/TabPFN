`SAMPLE_SUBSAMPLING_METHOD="majority_downsample"` now corrects the target prior shift it introduces. Predicted class probabilities are multiplied by the training-to-context class ratio, and the regression bar distribution is reweighted per bar from the sampler's inclusion probabilities; temperature tuning applies the same correction per holdout fold. Rankings are unchanged for binary classification and calibration improves for both tasks. Batched prediction is not supported with this sampler.
