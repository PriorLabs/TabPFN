Fit now keeps an inspection of its input in the fitted attribute `input_inspection_`: each column's label, dtype and a few of its values as received, the columns declared categorical through pandas' `category` dtype, and, for every column after date and text expansion, the modality decision together with the distinct-value count behind it, whether that count covered every row, and whether the values were numbers. Everything but the example values is read off state fit computes anyway, so the reading of a column can be explained later without another pass over the data. `detect_feature_modalities` returns these decisions next to the schema.
