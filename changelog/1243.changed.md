`load_fitted_tabpfn_model` and the `load_from_fit_state` class methods now default to `device="auto"`, matching the estimator constructors, instead of `device="cpu"`. The archive does not record the device a model was fitted on, so a GPU-fitted estimator silently reloaded onto CPU and predicted far slower with nothing to signal it — and assigning to `.device` afterwards could not fix it, since predict reads `devices_`. Code that relied on the old default to keep a GPU free must now pass `device="cpu"` explicitly.
