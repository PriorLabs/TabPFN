`fit` validates and cleans the input one range of columns at a time when reading it whole would convert all of it. The cleaned table is float32 when every ensemble member reads float32, as with GPU preprocessing. This reduces host memory for tables with integer, boolean, nullable, categorical, string, date or float64 columns. Predictions are the same as with a float64 table: the constant columns and the feature-importance order are decided on the input before the cast to float32. If float32 cannot hold the category or group codes exactly, the table stays float64.
