Add the `log_qgap`, `log_fixed_atom` and `log1p_target` regression target transforms for nonnegative targets. `log_qgap` and `log_fixed_atom` decode a range to exactly 0 for zero-inflated targets. `log1p_target` encodes log1p(c * y), with c set by `InferenceConfig.REGRESSION_LOG1P_SCALE`. Members that use them put no mass below 0.
