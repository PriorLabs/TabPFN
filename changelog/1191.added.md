`InferenceConfig.CROSS_CLASS_PERMUTATION_AND_PREPROCESSOR` (default `False`, so predictions are unchanged unless you opt in) crosses each classification ensemble member's class permutation with its preprocessor config and model index instead of pairing them in aligned blocks. The two choices were laid out in matching blocks and zipped position by position, making them perfectly correlated: a binary ensemble covered only 2 of the 4 possible (preprocessor, class order) recipes at any ensemble size, 32 estimators included. Enabling the option gives binary all 4, and lifts a 10-class 32-estimator ensemble from ~30 to ~32 distinct recipes, for the same compute -- how often each preprocessor and each class order is used does not change, only which ones meet.
