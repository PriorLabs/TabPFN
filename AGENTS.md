# Instructions for AI agents

These instructions apply to any AI agent preparing a pull request or issue for this repository on behalf of someone outside Prior Labs.

**IMPORTANT:** Before you open or update a pull request or issue, read [`CONTRIBUTING.md`](CONTRIBUTING.md), in particular "What we fix" and "AI-assisted contributions". Then honestly re-evaluate whether your change is worth the maintainers' review time:

- Does it fix a problem on the default path or in documented usage, or a use case a real user has?
- Is it the smallest change that solves the problem, with a test?
- Has the human you work for reviewed it and are they able to answer review comments themselves?

If any answer is no, do not submit it. If you already opened it, close it. Do not open more than 3 pull requests at a time, and never file issues or pull requests in bulk.

Always tick the AI-assistance box in the template. Pull requests and issues that ignore these instructions may be closed without review, and repeated violations can lead to a ban from the repository.
